# 执行计划

## 目标与已确认决策

构建本机只读磁盘分析 Web 应用，先交付一次快照的扫描、持久化与可视化闭环，再增加模型建议。首期 Windows 优先，同时接受指定目录和整盘作为扫描根。

- 前端：TypeScript + React + Vite，pnpm 管理。
- 后端：Python + FastAPI，uv 管理，SQLite 保存快照。
- 首期默认逻辑大小；快照表示扫描起止时间内的观察结果，不是文件系统级原子快照。
- 默认不读取正文、不计算全文件哈希、不跟随链接或目录联接。
- 扫描与路由分离，首期单扫描任务；进度轮询，不引入分布式队列。
- 可视化按需读取目录，倾向 Canvas；布局算法与绘制、交互分离。
- 全程不实现对被分析文件的写操作，应用自身数据库除外。

## M1：快照模型与只读扫描器

当前进度：用户已确认 [M1-SPEC.md](M1-SPEC.md) 的接口。M1–M4 实现与工程验收完成，真实符号链接和取消终态刷新均通过；证据与范围边界见 [M4-VALIDATION.md](M4-VALIDATION.md)。保留功能分支供用户体验，按任务分别本地提交，验收前不合并。

### 数据设计

- `scan_jobs`：任务 ID、目标路径、状态、扫描起止时间、已处理数量、累计大小、错误数。
- `snapshots`：根路径、统计口径、完成情况、扫描策略版本与汇总统计。
- `nodes`：快照 ID、父节点 ID、名称、类型、逻辑大小、目录汇总值、修改时间、可读状态。
- `scan_errors`：关联任务、节点或路径、错误类型和安全的错误描述。
- 对快照与父节点建立查询索引；批量插入并在收尾阶段完成自底向上聚合。
- 初期通过版本化迁移维护表结构；SQLite 使用单写入协调，确定连接、事务和异常回滚边界。

### 扫描实现

- 使用 `os.scandir()` 迭代遍历，避免 Python 递归深度限制；元数据访问禁止跟随链接。
- 校验扫描根的存在性、类型和访问权限；明确 Windows UNC 路径及重解析点支持边界。
- 单任务执行，提供取消信号与有界进度更新，不阻塞 FastAPI 事件循环。
- 捕获权限不足、文件消失、目录变化、长路径等异常；已读取结果可保留但必须标注不完整。
- 跳过应用数据库及其 WAL/SHM/journal 文件；当前政策为跳过符号链接、目录联接和其他重解析目标。
- 记录零字节文件、空目录；硬链接首期按目录项逻辑大小累计，并说明可能重复计数。
- 任务状态为 queued、running、completed、completed_with_errors、cancelled、failed；进程重启后将遗留运行任务标记为中断失败。

验收：在合成目录上验证大小聚合、空目录、Unicode 路径、错误记录、链接跳过、取消与中断恢复。验证扫描前后文件内容与元数据未被业务逻辑写入；不将操作系统访问时间变化当作应用写操作。

## M2：任务与快照 API

拟定接口在实现时确定请求响应模型并补充契约测试：

| 接口                                               | 用途                            |
| -------------------------------------------------- | ------------------------------- |
| `POST /api/scans`                                  | 校验目标并启动任务，返回任务 ID |
| `GET /api/scans/{id}`                              | 状态、计数、当前阶段与错误统计  |
| `POST /api/scans/{id}/cancel`                      | 请求取消任务                    |
| `GET /api/snapshots`                               | 分页列出保存的快照              |
| `GET /api/snapshots/{id}`                          | 快照口径、起止时间与汇总        |
| `GET /api/snapshots/{id}/nodes/{node_id}/children` | 排序、分页、按需返回目录子项    |
| `GET /api/snapshots/{id}/errors`                   | 分页查看扫描遗漏与原因          |

- 快照详情基于数据库记录，不隐式重新访问磁盘。
- 使用节点 ID 导航，验证节点归属，禁止通过相对路径越过扫描根。
- 为大目录提供可解释的“其他”聚合；确保可视化总量与明细分页口径一致。
- 仅监听回环地址；增加本地浏览器 Origin/Host 校验，避免开放任意 CORS。
- 扫描目标选择先提供路径输入与校验；目录浏览接口必须限制在明确允许的本机范围内。

验收：覆盖非法路径、并发任务拒绝、未知 ID、取消、分页、错误快照和进程重启。扫描期间健康检查与查询接口保持可响应。

## M3：快照可视化闭环

- 实现路径输入、开始扫描、状态轮询、取消、错误提示和快照列表。
- 实现 Treemap 布局：面积代表逻辑大小，颜色代表文件类型，边界表达目录层级。
- 实现目录下钻、面包屑、悬停详情、选中详情和大小排序列表。
- 小矩形聚合为“其他”，显示数量与总大小；零字节节点仍可通过列表查看。
- 仅查询当前视图需要的数据，避免全树传输和逐文件 DOM。
- 提供加载、空目录、全部不可读、部分失败、后端断开等状态。
- 使用列表与键盘导航补足 Canvas 可访问性。
- 后端托管前端构建产物，统一 `/api` 与页面同源访问；正确处理 SPA 回退与 API 404。

验收：选择目录完成扫描，打开快照、下钻与返回，刷新或重启后仍能打开。API 汇总、矩形面积权重与列表大小一致；完整构建后可本机运行。
