## 已确认架构

- Windows 优先、本机单用户，前后端分离；前端 TypeScript/React/Vite/pnpm，后端 Python/FastAPI/uv/SQLite。
- 扫描仅访问元数据，不读正文、不跟随重解析目标、不自动提权。应用数据库可写，模型不具备文件写入工具。
- 逻辑大小按目录项累计，硬链接可能重复计数；快照是扫描时间区间观察结果，不是原子或实时视图。
- 同一数据库单后端进程，单活动扫描和单活动分析分别管理。查询有界，前端按需加载，不全量读取文件树。
- 模型按 ModelAdapter、ModelRegistry、ModelCapacity 适配，首版固定证据 workflow；工具与 skill 契约预留，自主循环尚未启用。
