# SpaceAnalyzer v0.1.0 发布说明

准备日期：2026-10-31。状态：本地发布候选，用户已授权合并至 idle；尚未对外发布或创建正式版本标签。

## 本版用途

在 Windows 本机读取磁盘元数据，保存快照，用矩形树图和有界目录查询定位空间占用；可选择 DeepSeek 或本机 Ollama 根据快照证据对话，得到人工检查建议。应用不修改、移动或删除被分析文件。

## 包含能力

- 后台单扫描、进度、取消、遗漏记录、SQLite 历史及中断恢复。
- Canvas 矩形树图、按需分页、目录导航、文件详情、部分快照和历史重载。
- 本机 FastAPI API 与前端同源托管，支持源码构建后单进程运行。
- 多供应商统一适配、模型能力声明、本地 TOML/环境配置和预算限制。
- 固定证据 workflow、内置分析方法、流式对话、近期会话、证据定位及可重连事件。
- Windows 回收站重复提示汇总，保留可读大小与未知占用；不跟随重解析目标。

## 验证依据

完整 pre-commit 包含后端 31 项、前端 12 项、严格类型/lint、Python 编译和生产构建。扫描/可视化完成十万合成文件、128 层目录及已列出的 Windows 真实边界验证，见 [M4](../M4-VALIDATION.md)。

DeepSeek deepseek-flash 在本次合成数据中通过真实流式、事实与引用、多轮占比、取消、脱敏、浏览器及重启恢复，见 [DeepSeek 验收](../M5-DEEPSEEK-ACCEPTANCE.md)。本地 Ollama 的真实连通已验证，特定模型质量问题见下文。

## 已知限制与发布范围

- Ollama deepseek-r1:7b 的首轮内容验收出现最大目录判断错误及缺少引用。本次按用户授权作为已知限制发布，没有宣称修复，也不以 DeepSeek 结果替代本地模型验收。
- 模型回答、生成完成状态或有效引用均不能保证所有自然语言结论正确。检查证据后再人工决定，不提供自动清理操作。
- Windows 用户级旧 DeepSeek 凭据可能覆盖系统级有效值，旧进程也可能保留环境。常规后端需在启动终端配置正确凭据并重启；密钥不写入本地 TOML 或发行材料。
- 逻辑大小不同于实际分配空间，硬链接按目录项累计，快照不是原子视图。遗漏和取消的未知部分不按零计算。
- 同一数据库仅一个后端实例，历史界面有近期条数限制，上下文受预算约束。取消不能保证上游立即停止计费。
- 未包含 UNC、自动清理、实时监控、快照差异、重复内容哈希、百万节点实际扫描保证或桌面安装器。

## 安装与配置

本版准备提供 SpaceAnalyzer-v0.1.0-source.zip。解压后需要 Python 3.11+、Node.js 22.16+、pnpm 10、uv，按 [COMPOSE.md](../../COMPOSE.md) 安装锁定依赖、构建并启动。源码包不是包含运行时的独立可执行程序。

模型可选，默认关闭。复制 backend/config/models.example.toml 为 models.toml 后选择模型，API Key 只放后端进程环境。不配置模型也能使用扫描和可视化。

数据库默认位于当前工作树 data/snapshots.sqlite3。快照 schema 版本为 1、chat_meta 为 1、新扫描策略为 2。已有历史不会被重写，启动可能标记遗留运行中任务为中断失败；跨版本或工作树迁移前停止服务并备份应用数据库，勿让旧程序共享新版运行数据库。
