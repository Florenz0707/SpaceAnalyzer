## 凭据诊断

当前进程和用户级环境中的 DEEPSEEK_API_KEY 相同，模型目录请求返回 HTTP 401；系统级环境中存在另一份不同凭据，请求返回 HTTP 200。最小生成随后通过项目适配器，返回 OK，正常 stop，约 0.469 秒。

本次仅在隔离测试进程中使用通过验证的系统级凭据，未修改持久用户/系统环境或配置文件，未输出、提交或保存密钥。常规后端若继续继承旧的进程/用户级凭据，仍会鉴权失败；需要用户自行修正环境覆盖，再重启后端。应用不会自动回退使用其他作用域的密钥。

## 运行与界面验收

- 创建云端会话未明确同意时返回 400，显式同意后可运行。
- 相同请求键不重复生成；活动分析期间另一请求返回 409。
- 生成期间健康检查与快照查询可响应。
- 收到首段真实文本后取消，运行变为 cancelled，保留一个字符的已输出文本；不承诺供应商立即停止计算或计费。
- 已保存事件序号连续，终态存在；Last-Event-ID 重连只重放，不重新调用模型。
- Chrome 中真实发送问题得到正确总量和 E1 引用，证据按钮能定位最大文件所在目录。
- 刷新后恢复四次会话运行；后端进程重启后，正常及取消状态、回答与部分快照结果仍可读取，没有新增模型请求。
- 1600px 桌面和 390px 窄屏流程通过，窄屏无水平溢出；Chrome 控制台 0 errors / 0 warnings。

本次使用 1 次最小生成探针及 5 次业务生成（4 次完成、1 次取消）。已完成业务请求报告输入合计 6,052 token、输出合计 201 token；最小探针为 9/1 token。取消请求的最终用量未知，不按零计算，也未据此估算费用。

首轮与追问完成耗时约 1.140 秒、1.016 秒，首次可见文本约 0.656 秒、0.844 秒。以上是本机本次采样，不是性能承诺或压力测试结果。
